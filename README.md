# سفينة الإعراب — لغة الضياء

## التشغيل محليًا (اختياري، لمن يريد التجربة على جهازه)
```
npm install
npm run dev
```

## الرفع على الإنترنت (Vercel) — الأسهل
1. أنشئ حسابًا مجانيًا على github.com إن لم يكن لديك واحد.
2. أنشئ مستودعًا (Repository) جديدًا وارفع كل ملفات هذا المجلد إليه.
3. اذهب إلى vercel.com وسجّل الدخول بحساب GitHub نفسه.
4. اضغط "Add New Project" واختر المستودع الذي رفعته.
5. اترك كل الإعدادات كما هي (Vercel يكتشف Vite تلقائيًا) واضغط Deploy.
6. خلال دقيقة تقريبًا يعطيك رابطًا عامًا دائمًا مثل: safinat-alirab.vercel.app
